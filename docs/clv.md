# Closing Line Value

La closing line se define formalmente como la última cuota disponible del mismo
bookmaker entre el momento del pick y el inicio del evento, excluyendo cuotas
posteriores al kickoff y observaciones suspendidas.

El CLV se expresa como mejora de probabilidad implícita:
`1 / closing_odds - 1 / pick_odds`. Un valor positivo indica que la cuota de
cierre implicaba una probabilidad mayor que la disponible al registrar el pick;
no constituye una garantía de resultado.
